# 作業終了（/end）

1. この会話でやったことを振り返り、`git status --short` と `git diff --stat` で実際の変更も確認する。
2. `docs/PROGRESS.md` を更新する。
   - **作業日誌:** 今日の日付の見出しを、日誌の**一番上**に追加する（同じ日付があれば追記する）。「やったこと」「次にやること」を書く。
   - **📍 現在地:** 進捗 ％（表の下の目安に合わせる）、今いるステップ、次の一歩、やりかけを書き換える。
   - **🗺️ ロードマップ:** 終わったステップを ✅、途中のステップを 🔶 にする。
   - **🧠 つまずきメモ:** 今日間違えたことや迷ったことがあれば追記する。
3. ユーザーに次の形式で短く伝える。
   - **今日やったこと:** 3 行程度
   - **進捗:** 開始時 ○% → 現在 ○%
   - **次回の最初の一歩:** 1 行
4. OneDrive へのコピーは Stop フックが自動で行うので、手動でコピーしなくてよい。
5. 変更をコミットするか聞く（ユーザーのコードが含まれるため、勝手にコミットしない）。
