# 作業開始（/start）

1. `docs/PROGRESS.md` を読む。
2. `git status --short` と `git log --oneline -5` を確認し、PROGRESS.md に書かれていない変更（前回の終了後にユーザーが進めた作業など）がないか見る。あれば、その内容も踏まえる。
3. 次の形式で、日本語で短く伝える。
   - **現在地:** 進捗 ％ と今いるステップ（ロードマップの表から）
   - **前回やったこと:** 最新の日誌から 2〜3 行
   - **やりかけ:** あれば
   - **今日の目標:** 次の一歩を具体的に 1〜2 個
   - **復習クイズ:** 前回学んだ内容から 1 問（「つまずきメモ」を優先）
4. ユーザーは PHP / Laravel の初学者で、コードは自分で書く。答えのコードは書かず、クイズの答え合わせのあとに今日の最初の一歩を解説する。
5. 最初は `wsl` で Ubuntu に入り、`cd ~/dev/todo-app` で移動するよう一言添える。
